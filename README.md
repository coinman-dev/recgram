# RecGram

**RecGram — неофициальный клиент Telegram для Android с записью звонков.** Это форк официального приложения [Telegram for Android](https://github.com/DrKLO/Telegram) (автор исходного кода — Nikolai Kudashov и команда Telegram), распространяется по той же лицензии **GNU GPL v2** (см. [LICENSE](LICENSE)).

RecGram не связан с Telegram FZ-LLC и не одобрен ею. «Telegram» — товарный знак его владельцев.

## Возможности

- **Запись звонков** — личных аудио- и видеозвонков и групповых звонков.
  - Аудио: Opus, моно, 32/48/64 кбит/с (по умолчанию 48) → папка `Recordings/RecGram`.
  - Видео: MP4, H.265 или H.264 → папка `Movies/RecGram`.
  - Данные звонка (кто, кому, когда, длительность) → `Documents/RecGram/json`, а для аудио ещё и в тегах файла.
  - Имя файла: `Кто→Кому_ГГГГ-ММ-ДД_ЧЧ-ММ-СС`.
  - Громкость голосов выравнивается.
  - На экране звонка всегда видна отметка записи. Скрытой записи нет.
- **Правила записи по странам.** Перед первой записью вы выбираете страну, в которой находитесь:
  - зелёные — можно;
  - жёлтые — закон неоднозначен, решаете вы;
  - красные — только с уведомлением, его нельзя выключить;
  - серые — нельзя.

  Это справка, а не юридическая консультация.
- **Предупреждение собеседника**:
  - сообщением в чат до ответа на звонок;
  - голосом в начале разговора: сигнал → «Внимание. Этот разговор записывается…» → сигнал. Его слышат оба, и он попадает в запись.
- **Защищённый контент** (всё выключено по умолчанию): скриншоты везде, копирование и сохранение из чатов с запретом, переотправка вместо пересылки.
- Ставится **рядом с официальным Telegram**: свой пакет `app.recgram`, свой тип аккаунта.
- Карты — OpenStreetMap.

## Установка

1. Скачайте `RecGram-vX.Y.Z.apk` со страницы [Releases](../../releases).
2. Откройте файл на телефоне и разрешите установку из этого источника.
   Антивирусы и «Защита приложений» Samsung могут предупреждать о неизвестном приложении — это обычная реакция на APK не из Google Play.
3. Обновления ставятся поверх: все релизы подписаны одним ключом.

Нужен Android 6.0 или новее, процессор ARM (почти все телефоны).

## Первый запуск: свой API-ключ

У RecGram **нет общего API-ключа**: каждый пользователь работает со своим. Это бесплатно и занимает пару минут:

1. Откройте [my.telegram.org](https://my.telegram.org) и войдите по номеру телефона (код придёт в Telegram).
2. Откройте **API development tools**.
3. Заполните форму: любое название, короткое имя латиницей, платформа **Android**.
4. Скопируйте **App api_id** (число) и **App api_hash** (32 символа) в экран первого запуска RecGram.

Если форма отвечает «ERROR», попробуйте без VPN, в другом браузере или позже. На одном аккаунте можно создать только одно приложение.

Ключ хранится только на вашем телефоне. Сменить его: **Настройки → RecGram → API-ключ**.

## Уведомления

Telegram отправляет push-уведомления только официальным приложениям. Поэтому RecGram держит фоновое соединение: переключатель есть на экране первого запуска и в настройках уведомлений. Чтобы Android не закрывал соединение, разрешите RecGram работу в фоне без ограничений батареи.

## Законность записи

Запись разговоров регулируется законами страны, где вы находитесь, а иногда и страны собеседника. В некоторых странах нужно согласие всех участников. Ответственность за запись несёт пользователь. Встроенные правила по странам — справка, не юридическая консультация.

## Для разработчиков

Новый код — в пакете `org.recgram` (`TMessagesProj/src/main/java/org/recgram`). В исходные файлы Telegram внесены только точечные вызовы, каждый отмечен комментарием `// RecGram`. Скрипты, которыми вносятся эти правки, — в `recgram/tools/patches`; полный список изменений — в истории git после коммита `7be672ead` (Telegram 13.2.1).

Сторонний код: провайдер карт `OSMDroidMapsProvider` взят из [Nullgram](https://github.com/qwq233/Nullgram) / [Nnngram](https://github.com/NextAlone/Nnngram) (GPL-2.0-or-later) и адаптирован.

### Сборка

Нужны JDK 17, Android SDK 36, NDK 27.2.12479018, CMake 3.22.1 и подмодули:

```
git submodule update --init --recursive
./gradlew :TMessagesProj_App:assembleAfatDebug
```

Ключ подписи и его пароли — в папке `secrets/` (в git не попадает), см. [secrets/README.md](secrets/README.md). Без него APK подписывается тестовым ключом Telegram.

PNG-иконки для Android 6–7: `python recgram/tools/make_icons.py TMessagesProj/src/main/res` (нужен Pillow).

### Релизы

Тег `v*` → GitHub Actions собирает подписанный APK (arm64-v8a и armeabi-v7a) и публикует его в Releases. `v1.2.3` — стабильный релиз, `v1.2.3-beta.1` / `v1.2.3-rc.1` — пререлиз. Ручной запуск workflow **Release** даёт APK как артефакт на 3 дня, без релиза.
