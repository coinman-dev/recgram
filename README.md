# RecGram

**RecGram — неофициальный клиент Telegram для Android.** Это форк официального приложения [Telegram for Android](https://github.com/DrKLO/Telegram) (автор исходного кода — Nikolai Kudashov и команда Telegram), распространяется по той же лицензии **GNU GPL v2** (см. [LICENSE](LICENSE)).

RecGram не связан с Telegram FZ-LLC и не одобрен ею. «Telegram» — товарный знак его владельцев.

Оригинальное описание проекта Telegram сохранено в [TELEGRAM_README.md](TELEGRAM_README.md).

## Чем RecGram отличается от Telegram

- **Запись личных звонков**: Opus, моно, 64 кбит/с, папка `Recordings/RecGram`, данные звонка в тегах файла. На экране звонка всегда видна отметка записи, скрытой записи нет.
- **Правила записи по странам**: перед включением записи пользователь выбирает страну; страны отмечены цветом (можно / непонятно — решает пользователь / нельзя — запись выключена). Справка, не юридическая консультация.
- **Предупреждение собеседника** о записи сообщением в чат до ответа на звонок.
- **Выравнивание громкости** голосов в записи.
- **Защищённый контент** (всё выключено по умолчанию): скриншоты, копирование и сохранение, переотправка вместо пересылки.
- Свой пакет `app.recgram`, свой тип аккаунта — ставится рядом с официальным Telegram.

## Изменённые файлы

Новый код — в пакете `org.recgram` (`TMessagesProj/src/main/java/org/recgram`). В исходные файлы Telegram внесены только точечные вызовы, каждый отмечен комментарием `// RecGram`. Скрипты, которыми вносятся эти правки, — в `recgram/tools/patches`; полный список изменений — в истории git после коммита `7be672ead` (Telegram 13.2.1).

## Сборка

Нужны JDK 17, Android SDK 36, NDK 27.2.12479018, CMake 3.22.1 и подмодули:

```
git submodule update --init --recursive
```

Свой API-ключ Telegram (https://my.telegram.org → API development tools) задаётся в `local.properties`, в репозиторий он не попадает:

```
RECGRAM_API_ID=...
RECGRAM_API_HASH=...
```

Отладочная сборка:

```
./gradlew :TMessagesProj_App:assembleAfatDebug
```
